검토일: 2026-10-18. 최초 배너 14행·캐릭터 26행 초안과 이후 사용자가 붙여준
두 원문 내용을 현재 KR 게임 데이터와 대조한 기록이다. 커뮤니티에서 실제로 사용되는지와 이름·ID가 맞는지는

## 출처와 확인 범위

- 사용자가 제공한 정리표: 검토 대상 초안이며 검증된 별명 사전으로 취급하지 않는다.
- [냥코 줄임말 사전](https://arca.live/b/battlecat/46071094),
  [추가 줄임말 자료](https://arca.live/b/nyanko/74042366): 사이트 직접 조회는 실패했으나
  사용자가 두 글의 본문을 붙여 주어 해당 텍스트의 용례를 확인했다. 게시일·수정일과
  현재 웹페이지 일치 여부는 독립 확인하지 않았다. 원문의 댓글 요청·조작 지시 등은 실행 지침이 아니다.
- 데이터 대조: `Route.ball_kr.cats`의 모든 형태 이름·희귀도,
  `EventSeriesNames::Korean/Shortcuts`, 기존 MCP 검색 코드와 `character-notes.json`.
- 기존 검증 출처: [티어 자료의 ID 연결](gpt-tier-sources.md). 이미 확인한 연결만 재사용한다.

이 문서는 검토 기록이다. 승인한 별명은 `gpt-knowledge/character-aliases.json`에 ID와
출처로 유지하고, 일반 용어 안내는 `gpt-knowledge/glossary.md`로 제공한다.
한국어 축약은 정식 이름의 연속 부분 문자열일 필요가 없다. 문단→문어단지,
라길→라면의 길, 암테→아마테라스처럼 대상이 확인되는 표현을 등록한다.

## 운영 반영 기준

1. 배너 별명은 시리즈로, 캐릭터 별명은 캐릭터 ID로 분리한다.
2. 모든 형태 이름으로 이미 검색되는 표현은 중복 등록하지 않아도 된다.
   정식 이름과 불연속인 한국어 축약도 현재 데이터의 대상이 명확하면 별명으로 등록한다.

4. 새 별명 등록에는 실제 용례 출처와 검토일을 남기고, 이름·형태·속성은 기존 데이터에서 읽는다.
5. 사전 변경 시 이 검토표를 갱신하고 MCP 검색으로 단일/복수 결과를 검증한다.

### 교정·보류

- **레티=레전드 티켓은 오류**다. 레티는 레어 티켓으로 유지하고 레전드/블티와 구분한다.
- **베카→고양이 신지 연결은 반영하지 않는다.** 기존 베카는 60 고양이 베이비(3진 베이비카트)다.
  고양이 신지는 별도 ID 416이며 베카를 추가하지 않는다.
- 쇼콜라디테를 걸즈 몬스터즈에, 요수 가루/가오를 다이너마이트 군단에 넣은 원문 분류는
  배너 소속 근거가 아니다. 트로피칼 칼리파도 빅쿠리맨 소속이라고 고정하지 않는다.
  아레스/백호/무사시 등의 시리즈도 실제 event 슬롯으로 확인한다.
- ‘풍냥탑 공무원’, ‘포노스의 딸’은 시점/문맥 의존 평가 별칭으로 단일 ID 등록을 보류했다.
  ‘유키냥’은 식별 대상 182가 EX라 현재 MCP 뽑기 검색 범위 밖이다. ‘개호기’ 등 비하/평가성 표현은 새 식별 사전에 넣지 않았다.
- 자료의 검심 ID 879~882·업데이트/복각 설명도 현재 데이터 확인 없이 새 정식 이름/ID로 추가하지 않는다.
