# Catsroll 공개 제출 준비

## 현재 단계

공개용 패키지 준비 중이다. 디렉터리 제출·승인·공개는 완료하지 않았다.
원본 비공개 플러그인과 App 연결은 보존하며, 별도 공개 ZIP은 기존 HTTPS MCP를 선언한다.
플러그인 소스 버전은 `plugins/catsroll/plugin.json`, 서버 구현 버전은 `local/gpt_mcp.rb`가 각각 기준이다.

확정한 운영 설정:

- 지원 국가: 한국(`KR`). 데이터 지역 선택 KR/JP와 디렉터리 국가 제한은 별도다.
- 무료 제공, 결제·상품 구매 기능 없음.
- 문의: 공개 [GitHub Issues](https://github.com/twkim96/catsroll/issues).
- 유지할 MCP 주소: `https://twkim96-my-cats-rolls.hf.space/mcp`.
- 게시자 공개명은 개인 인증 화면에서 확인한 뒤 소유자가 결정한다. `twkim`을 임의로 인증명으로 선언하지 않는다.

## 다음에 필요한 사용자 작업

OpenAI Platform 조직 설정의 개인 인증 시작 시 유효한 기본 결제수단을 요구했다.
카드 입력 뒤 초기 크레딧 구매 화면에서 멈춘 상태로 조직 설정의 개인 인증을 다시 시도하자
`Verify your identity → Start ID Check`가 열렸다. 이 계정에서는 초기 $5 구매 전에도
Persona 본인 인증을 시작할 수 있는 화면까지 진입했다. 소유자는 Persona의 완료 화면을 확인했고,
OpenAI 조직 설정에는 `Identity in review`가 표시된다. OpenAI 승인·게시자명 확인은 아직 남아 있다.
카드 등록·구매·자동 충전·신분증 제출은 소유자가 직접 결정한다.
API 선불 결제는 ChatGPT Business 구독 및 ChatGPT 워크스페이스 크레딧과 별개다.
현재 플러그인 서버는 OpenAI API를 호출하지 않는다. 초기 API 크레딧 구매를 플러그인 등록 수수료로 안내하지 않는다.
개인 인증 뒤 실제 공개명을 확인하기 전에는 공개 배포를 진행하지 않는다.

`CATSROLL_GPT_UI_ORIGIN`으로 고유 UI origin을 지정하며 미지정 시 MCP 공개 origin을 쓴다.
공개 서버의 메타데이터 반영만으로 실제 공개 CSP 수용 통과로 보지 않는다.
기존 PONOS 아이콘은 오리지널 발바닥으로 교체했다. 생성 경위를 공개하고 상표 조사나 독점 권리 확보까지 주장하지 않는다.
최종 제출의 사실·권리 attestation은 여전히 소유자가 확인한다.
심사용 녹화 URL·인증명·정책 URL을 임의로 채우지 않는다. 누락 자료가 있는 ZIP은 제출 준비 완료본이 아니다.

## 페이지와 도메인 인증 준비

`local/gpt_public_pages.rb`와 `view/gpt_public/`에서 다음 경로를 제공한다.

- `/gpt/about`: 기능·소스·공개 상태·GitHub Issues 안내.
- `/gpt/privacy`, `/gpt/terms`: 개인정보처리방침·이용약관. 운영자는 기존 공개 선호인 twkim/GitHub twkim96로 표기.
- `/.well-known/openai-apps-challenge`: 포털에서 발급한 단일 토큰의 plain text 응답.

안내 페이지는 `CATSROLL_GPT_PUBLIC_PAGES=1`로 활성화된다. 라이브러리 기본은 404이며
HF 루트 Dockerfile은 0.2.3부터 활성화한다. manifest의 소개·정책·약관 URL을 같은 HF origin으로 연결한다.
패키징 시 `CATSROLL_PUBLIC_ORIGIN`을 바꾸면 이 세 URL과 MCP URL을 함께 바꾼다.
디렉터리 게시자명은 별도로 인증 승인 후 확인하며 정책 표기를 인증명으로 속이지 않는다.

도메인 인증은 `CATSROLL_OPENAI_DOMAIN_CHALLENGE`에 실제 토큰을 설정한다. 비어 있거나
제어 문자·4,096바이트 초과 값이면 404이며, 유효한 값은 공백도 가공하지 않고 정확히 반환한다.
인증 경로는 안내 페이지 활성화와 별개이며 GET/HEAD만 허용한다. 실제 토큰은 저장소에 넣지 않는다.
현재 포털에서는 인증된 게시자가 없으면 ZIP 업로드 자체를 시작할 수 없으므로 토큰도 아직 발급되지 않았다.

현재 패키지의 정상 사례는 초심자·속성 추천·Multi·Find·미정 배너의 정확히 5개이며 부정 사례는 3개다.
사용자 시드 대신 합성 샘플 42를 사용한다. 별명 사례는 제품 회귀 검사를 유지하되 제출 사례 수에는 포함하지 않는다.
공식 제출 규칙은 정확히 5/3이며, 부분 목록 ZIP 업로드 허용을 최종 제출 통과로 해석하지 않는다.

## 심사 사례의 검증 상태

0.2.0은 기존 GPT 입력 디자인 아래에 공통 Multi의 Found cats·Find·플랜을 통합했다.
로컬 모의 호스트의 통합 검사는 통과했으며 실제 제출 호스트 재검증은 남아 있다.

사례 본문과 기대 도구/동작은 manifest의 `extensions.com.openai.review.test_cases` 한 곳에서 관리한다.

| 사례 | 서버/로컬 확인 | 실제 제출 버전의 ChatGPT 확인 |
| --- | --- | --- |
| 초심자 안내 | 검색·설명 경계 확인 | Business Instant: 짧은 안내와 시드 유무 질문 확인. 안내 도구 조회 내역은 UI에서 확인되지 않아 검색 경로 수용은 보류 |
| 빨간 적+천사 추천 | 대상 속성·조건·출처 연결 확인 | Business Instant: 답변 표시됨. 조회 내역·복수 속성 및 평가 조건 준수는 미확인. 메탈 크리캐 추가 질문에는 나나호·스탈 및 크리티컬 여부를 구분 |

| 별명과 카이 투자 조건 | ID 연결·초본능 조건 응답 확인 | Not run |

| 부정 사례 3개 | 해당 동작을 실행할 API 없음 | Business Instant: 대리 뽑기·서버 시드 조작 불가, 미발표 날짜와 영구 종료 단정 불가를 각각 설명. 자격증명 요청이나 실행 성공 주장은 없었음 |

API 직접 호출 통과를 실제 모델 도구 선택·사용자 설명 통과로 표시하지 않는다.
Business의 최소 추론 메뉴는 `Instant`로 표시됐지만 무료 계정 수용 검사를 대신하지 않는다.
앞선 0.2.1 시험에서는 `CSP 꺼짐`이 표시됐다. 이후 강제 적용을 켠 시험 결과는 준비 표와 아래 조사에 구분한다.
경로 상세에서 플래티넘 비용이 +2로 고정되어 합계 1과 달랐던 표시 오류는 티켓 종류별로 수정했다.
공통 Multi의 표시이므로 웹 Multi와 GPT 앱에 함께 적용되며, 기존 브라우저 회귀에서 상세/합계의 일치를 확인했다.
실제 호스트의 첫 앱 표시 실패는 Find·참고 배열·Multi 세 요청에서 반복됐고,
재시도 후 별도 앱 패널에서는 정상 실행됐다. 원인은 아직 특정하지 못했으며 비용 표시 수정과 별개다.
시연은 위 흐름을 순서대로 보여 주되 비밀번호·카드·다른 채팅을 녹화하지 않는다.
현 시점에는 검증된 실제 시연 영상이 없다. 기능이 정상 표시되는 시험 계정에서 리허설 후
화면 녹화 도구로 실제 대화를 기록하고, 재생 및 심사자 접근 URL을 확인해 manifest에 추가한다.

## 응답 오류 조사

2026-10-17 서버 0.2.2를 Business Instant에서 합성 입력으로 재검사했다.
사용자 실제 대화와 별도의 진단 대화를 사용했으며, 첫 로딩 중 앱 열기 버튼을 누르지 않았다.

| 구분 | 실제 관찰 |
| --- | --- |
| MCP 없는 일반 답변 | 한 문장 응답과 단순 산술 응답 두 요청 모두 `이 응답을 불러오지 못했습니다` |
| UI 없는 안내 요청 | 처리 내역에 A/B 트랙 안내 완료가 표시됐지만 답변 본문은 같은 표시 오류 |
| 계산 앱 첫 표시 | 10회·1회 새 카드 모두 `Catsroll을(를) 표시하지 못했습니다`. 계산 실행 전 발생 |
| 같은 카드 재시도 | 두 카드 모두 ChatGPT 연결 및 설정 수신. 첫 카드에서 A/B 각 10행 기기 계산 완료 |
| 결과 공유 | 앱에 `계산 요약을 GPT에 전달했습니다` 표시. 후속 답변 본문은 같은 표시 오류 |

첫 표시 중 바깥 sandbox iframe은 생성됐지만 접근성 트리는 `about:blank`였고,
앱 DOM은 확인되지 않았다. 재시도에서는 내부 Catsroll 문서·연결 상태·배너 데이터가 표시됐다.
앱 코드가 첫 실패의 어느 단계까지 실행됐는지는 이 관찰만으로 확정할 수 없다.
새 카드의 첫 표시 실패는 같은 대화에서 데이터 수신·계산을 완료한 뒤에도 반복됐다.
계산 횟수나 Find 탐색 부하를 원인으로 단정하지 않는다.

같은 시점 공개 MCP 직접 호출의 initialize·리소스 목록/읽기·bootstrap·Multi 준비는
모두 HTTP 200, RPC 오류 없이 약 0.6~1.9초에 응답했다. UI 리소스 JSON 응답은
약 622KB, bootstrap은 약 1.42MB였다. 단일 측정이므로 장기 지연·cold start·호스트
전송 경로까지 보장하지 않으며, 크기만으로 부하 원인도 배제하지 않는다.

현재 증거는 **답변 표시 오류가 Catsroll 없이도 발생한다**는 점과 **앱 첫 표시/재시도의
동작 차이**를 확인한다. ChatGPT의 대화·sandbox 표시 경로를 우선 의심하지만,
정확한 원인과 Catsroll 초기 연결의 기여 여부는 미확정이다. 진단 탭의 콘솔에서는
원인을 특정할 오류가 확인되지 않았다. 크레딧 소진 배너나 이전 확장 오류 하나만으로
원인을 확정하거나 API 충전을 해결책으로 제시하지 않는다.

공개 전 남은 수용 조건은 새 앱 카드가 재시도 없이 표시되고, 공유 뒤 답변도 정상 표시되는 것이다.
문제가 없는 별도 브라우저/계정 환경과 비교하거나 호스트 측 실패 추적이 필요하다.
바깥 sandbox의 첫 표시 실패 원인은 미확정이다. 별도로 실제 시드 찾기 시험에서
준비 결과가 bootstrap보다 먼저 도착하면 초기 mount가 seeker payload를 지우는 순서 오류를 발견했다.
0.2.3은 이를 보존하며, bootstrap을 지연한 회귀에서 10개 관측 입력과 한 번 클릭 시드 복구를 검사한다.
이 수정이 바깥 sandbox 표시나 일반 답변 오류까지 고친다고 주장하지 않는다.
ChatGPT의 사용자 지정 앱 CSP 강제 적용은 켰으며 보안 정책을 완화하지 않았다.

## 정책과 권리 사전 준비

정책 본문은 `view/gpt_public/privacy.html`, 약관은 `terms.html`이 유지 위치다.
운영자는 기존 공개 이름 twkim/GitHub twkim96, 시행일은 2026-10-17로 정리했다.
공개 이메일과 문의 종결 후 1년 이내 운영자 삭제는 소유자가 앞서 정한 조건이다.

`config/yahns.rb`·`server.rb`·`local/server_middleware.rb`·`gpt_mcp.rb`를 확인했다.
정상 MCP 본문을 별도 기록하는 미들웨어나 요청 이력 DB는 없으며, Yahns는 서버 진단과
예외 메시지·스택을 stdout/stderr로 전달할 수 있다. 이를 모든 호스팅 로그의 부재로
확대하지 않는다. HF 인프라의 보관 기한을 추정해 쓰지 않고 제공자 방침에 연결했다.
정책이 구현하는 자동 로그 삭제 기능이나 자동 메일 삭제는 없다.
HF 0.2.3에서 `/gpt/about`, `/gpt/privacy`, `/gpt/terms`가 모두 HTTP 200이며 운영자 표기와 초안 문구 제거를 확인했다.
현재 공개 리소스에 새 발바닥 아이콘과 초기 seeker payload 보존 코드가 포함되는지도 확인했다.
배포 후 도구 새로고침과 새 대화에서 0.2.3 코드·아이콘, 관측 10개 보존 및
계산 버튼 한 번으로 시드 42 복구를 실제 확인했다. 기존 대화의 캐시된 앱은 예전 코드를 유지할 수 있다.

포털에서 Upload를 다시 열었으나 `You need a verified developer identity before you can
create or upload a plugin`으로 차단됐다. 따라서 실제 challenge 발급·MCP 연결·자동 검사는
현재 진행할 수 없다. challenge 서버 구현과 패키지는 준비된 상태이며 토큰은 임의로 만들지 않는다.

## 실제 시연 준비

녹화할 프롬프트·기대 도구·결과는 manifest의 5개 긍정/3개 부정 사례를 그대로 사용한다.
별도 대화와 합성 시드 42만 쓰고 계정 설정·인증·메일·다른 채팅은 촬영하지 않는다.

1. Instant에서 초심자 질문과 빨간 적+천사 추천을 실행해 실제 안내·출처·투자 조건을 확인한다.
2. Multi 사례는 앱의 수동 계산 → A/B 각 100행·11회 확정 → 결과 공유 순서로 보여 준다.
3. Find 사례는 칼리파·플래티넘 1장 조건 → 수동 계산 → 다음 2A·목표 도장 → 결과 공유와 답변을 보여 준다.
4. 미정 검심 사례는 JP 원본 날짜·한국어 이름 fallback·KR 미확정 경고와 참고 배열을 보여 준다.
5. 부정 3개는 실제 게임 조작·미발표 일정 확정·시드 변경을 실행하지 않는 답변을 확인한다.
6. 녹화 재생·심사자 접근 가능 여부를 확인한 실제 URL만 `review.demo_recording_url`에 넣는다.

현재 ChatGPT 첫 로딩/답변 표시 오류 때문에 정상 시연 완료로 표시하지 않는다.
브라우저 제어에는 녹화 기능이 노출되지 않았다. 정상 환경 확보 후 창 녹화로 실제 흐름을 촬영해야 한다.
로컬 모의 호스트 녹화나 정지 화면 모음을 실제 ChatGPT 시연으로 대체하지 않는다.
CSP 강제 적용을 켠 Business Instant에서 Find 칼리파/플래티넘 1장/다음 2A와
WASM 합성 관측 10개 → 시작 시드 42·관측 후 3562635250 복구를 확인했다.
결과 공유는 전달 완료 응답을 받았다. 첫 로딩 재시도와 답변 본문 오류는 남아 있다.
무료 계정 검사는 별도 로그인 가능한 시험 환경이 있어야 하며 Business Instant 통과로 대체하지 않는다.

## 업데이트와 이전

이벤트/게임 데이터 및 호환되는 서버 결과 수정은 기존 HF 배포로 제공된다.
도구·스키마·설명·instructions·UI 참조/CSP 변경은 공개 후 지속 자동 검토를 거친다.
소개·아이콘·국가·패키지/skill 변경은 기존 플러그인의 새 ZIP과 버전 심사가 필요하다.

현재 제출 안내는 기존 MCP 서버 URL 변경을 포털에서 지원하지 않으므로 OpenAI 지원팀에 문의하라고 안내한다.
경로만 바꾸면 자동 수정된다고 가정하지 않는다. 지원팀 안내에 따라 새 등록이 필요한 경우에도
현재 서버·엔진·자료를 재사용할 수 있다. 새 endpoint와 UI origin, 공개 링크를 설정하고 도메인 검증·심사를 완료한다.
기존 사용자에게 새 플러그인 설치/연결을 안내하며 기존 설치가 자동 이전된다고 가정하지 않는다.
공개 도구 정의와 이미 발급한 UI resource URI는 전환 중에도 호환성을 유지해야 한다.
