# Catsroll 공개 제출 준비

## 현재 단계

공개용 패키지 준비 중이다. 디렉터리 제출·승인·공개는 완료하지 않았다.
원본 비공개 플러그인과 App 연결은 보존하며, 별도 공개 ZIP은 기존 HTTPS MCP를 선언한다.
플러그인 소스 버전은 `plugins/catsroll/plugin.json`, 서버 구현 버전은 `local/gpt_mcp.rb`가 각각 기준이다.

확정한 운영 설정:

- 지원 국가: 한국(`KR`). 데이터 지역 선택 KR/JP와 디렉터리 국가 제한은 별도다.
- 무료 제공, 결제·상품 구매 기능 없음.
- 문의: 공개 [GitHub Issues](https://github.com/twkim96/catsroll/issues).
- 유지할 MCP 주소: `https://twkim96-my-cats-rolls.hf.space/mcp`.
- 게시자 공개명은 개인 인증 화면에서 확인한 뒤 소유자가 결정한다. `twkim`을 임의로 인증명으로 선언하지 않는다.

## 다음에 필요한 사용자 작업

OpenAI Platform 조직 설정의 개인 인증 시작 시 유효한 기본 결제수단을 요구했다.
카드 입력 뒤 초기 크레딧 구매 화면에서 멈춘 상태로 조직 설정의 개인 인증을 다시 시도하자
`Verify your identity → Start ID Check`가 열렸다. 이 계정에서는 초기 $5 구매 전에도
Persona 본인 인증을 시작할 수 있는 화면까지 진입했다. 소유자는 Persona의 완료 화면을 확인했고,
OpenAI 조직 설정에는 `Identity in review`가 표시된다. OpenAI 승인·게시자명 확인은 아직 남아 있다.
카드 등록·구매·자동 충전·신분증 제출은 소유자가 직접 결정한다.
API 선불 결제는 ChatGPT Business 구독 및 ChatGPT 워크스페이스 크레딧과 별개다.
현재 플러그인 서버는 OpenAI API를 호출하지 않는다. 초기 API 크레딧 구매를 플러그인 등록 수수료로 안내하지 않는다.
개인 인증 뒤 실제 공개명을 확인하기 전에는 공개 배포를 진행하지 않는다.

## 준비한 것과 남은 자료

| 항목 | 상태 |
| --- | --- |
| HTTPS MCP 및 7개 도구 | 공개 서버에서 조회/준비 응답 확인. 앱 전용 전송 도구 포함 |
| 공개 소개·문의 | `gpt-overview.md`, GitHub Issues |
| 아이콘 | 270×270 PNG, 실제 파일·출처는 `plugins/catsroll/assets/` |
| 심사 사례 | manifest에 긍정 5개·부정 3개 수록 |
| 지원 국가·무료 선언·릴리스 설명 | manifest 수록 |
| 인증 게시자·공개명 | Persona 제출 완료, OpenAI `Identity in review`. 승인·공개명 확인 대기 |
| 개인정보처리방침·약관 | `view/gpt_public/`에 검토용 HTML 초안 준비. 운영자·보관 방침·비공개 연락 방법 확정 후 정식 문서로 게시해야 함 |
| UI 전용 origin·공개 CSP | 리소스 `ui.domain` 기본값을 MCP 공개 origin으로 준비. 배포 후 실제 호스트 CSP 검증 필요 |
| 도메인 challenge | 정확한 환경 변수 토큰만 응답하는 경로 준비. 포털 토큰 발급·HF 설정·Verify Domain은 미완료 |
| 실제 ChatGPT 심사 사례·시연 녹화 | 현재 계정 응답 오류/크레딧 상태 때문에 완료되지 않음 |
| 무료 계정 설치·사용 | 미검증 |
| 제출 attestation | 소유자가 실제 사실과 권리 범위를 확인하고 직접 완료 |

`CATSROLL_GPT_UI_ORIGIN`으로 고유 UI origin을 지정하며 미지정 시 MCP 공개 origin을 쓴다.
이 변경을 배포하고 실제 공개 CSP 검증을 마치기 전에는 공개 수용 통과로 보지 않는다.
게임 아이콘의 출처 표기만으로 공개 배포 권리까지 확인됐다고 주장하지 않는다.
심사용 녹화 URL·인증명·정책 URL을 임의로 채우지 않는다. 누락 자료가 있는 ZIP은 제출 준비 완료본이 아니다.

## 페이지와 도메인 인증 준비

`local/gpt_public_pages.rb`와 `view/gpt_public/`에서 다음 경로를 제공한다.

- `/gpt/about`: 기능·소스·공개 상태·GitHub Issues 안내.
- `/gpt/privacy`, `/gpt/terms`: 소유자 검토용 초안. 현재 정식 정책이 아니다.
- `/.well-known/openai-apps-challenge`: 포털에서 발급한 단일 토큰의 plain text 응답.

안내 페이지는 `CATSROLL_GPT_PUBLIC_PAGES=1`로만 활성화되며 기본은 404다.
검토 전 초안을 공개 정책 URL로 제출하지 않는다. 로컬 검토는 기존 preview 서버에 이 환경 변수를 지정한다.
완성 후 같은 HF origin의 실제 공개 페이지를 검사하고 manifest의 URL 필드에 연결한다.

도메인 인증은 `CATSROLL_OPENAI_DOMAIN_CHALLENGE`에 실제 토큰을 설정한다. 비어 있거나
제어 문자·4,096바이트 초과 값이면 404이며, 유효한 값은 공백도 가공하지 않고 정확히 반환한다.
인증 경로는 안내 페이지 활성화와 별개이며 GET/HEAD만 허용한다. 실제 토큰은 저장소에 넣지 않는다.
현재 포털에서는 인증된 게시자가 없으면 ZIP 업로드 자체를 시작할 수 없으므로 토큰도 아직 발급되지 않았다.

패키지 0.2.1의 정상 사례는 초심자·속성 추천·Multi·Find·미정 배너의 정확히 5개이며 부정 사례는 3개다.
사용자 시드 대신 합성 샘플 42를 사용한다. 별명 사례는 제품 회귀 검사를 유지하되 제출 사례 수에는 포함하지 않는다.
공식 제출 규칙은 정확히 5/3이며, 부분 목록 ZIP 업로드 허용을 최종 제출 통과로 해석하지 않는다.

## 심사 사례의 검증 상태

0.2.0은 기존 GPT 입력 디자인 아래에 공통 Multi의 Found cats·Find·플랜을 통합했다.
로컬 모의 호스트의 통합 검사는 통과했으며 실제 제출 호스트 재검증은 남아 있다.

사례 본문과 기대 도구/동작은 manifest의 `extensions.com.openai.review.test_cases` 한 곳에서 관리한다.

| 사례 | 서버/로컬 확인 | 실제 제출 버전의 ChatGPT 확인 |
| --- | --- | --- |
| 초심자 안내 | 검색·설명 경계 확인 | Blocked: 일반 응답 표시도 실패 |
| 빨간 적+천사 추천 | 대상 속성·조건·출처 연결 확인 | Blocked: 추천 질문 응답 표시 실패 |
| Multi 100회·11회 확정 | 원본 엔진 및 기존 개발 연결에서 실행 확인 | Not run: 공개 CSP/제출 버전 별도 |
| 플래티넘 Find | 기존 개발 연결에서 티켓 1회·다음 2A 확인 | Not run: 제출 버전 별도 |
| 별명과 카이 투자 조건 | ID 연결·초본능 조건 응답 확인 | Not run |
| 미정 콜라보 참고 배열 | 검심의 KR/JP 최신 풀 연결·이름 fallback·원본 슬롯 보존·참고 표시 전달 확인 | Not run |
| 부정 사례 3개 | 해당 동작을 실행할 API 없음 | Not run: 모델의 도구 미호출/설명 확인 필요 |

API 직접 호출 통과를 실제 모델 도구 선택·사용자 설명 통과로 표시하지 않는다.
시연은 위 흐름을 순서대로 보여 주되 비밀번호·카드·다른 채팅을 녹화하지 않는다.
현 시점에는 검증된 실제 시연 영상이 없다. 기능이 정상 표시되는 시험 계정에서 리허설 후
화면 녹화 도구로 실제 대화를 기록하고, 재생 및 심사자 접근 URL을 확인해 manifest에 추가한다.

## 응답 오류 조사

같은 개발용 ChatGPT 대화에서 MCP 없는 ‘정상’ 한 단어 응답도 동일한 표시 오류가 발생했다.
새 대화 첫 화면에는 ‘워크스페이스 크레딧 소진’이 표시됐다. Catsroll 도구의 크기나 계산량만으로
설명할 수 있는 현상이 아니다. 계정 사용량·대화·브라우저/호스트 표시 경로가 우선 조사 대상이며,
크레딧 표시 하나만으로 원인을 확정하거나 API 충전을 해결책으로 제시하지 않는다.

공개 서버에서 ping·단일 캐릭터·안내·추천·Multi 준비는 HTTP 200, RPC/도구 오류 없이 응답했다.
해당 조사 표본의 도구 응답은 약 0.6~0.9초, 0.3~16KB였으며 UI 리소스는 약 215KB/1.4초였다.
단일 표본이므로 장기 성능·cold start 보장이 아니다. 콘솔에는 브라우저 확장의 오류도 있었지만
해당 응답 실패의 원인이라고 입증되지 않았다. 구체적인 프로토콜 결함은 정적 독립 검토에서 확인되지 않았다.

## 개인정보처리방침 검토용 사실

이 절은 운영 사실과 미결정을 정리한 초안이며 게시된 개인정보처리방침이 아니다.

- MCP 입력에는 요청에 따라 지역·배너·캐릭터·시드·뽑기 관측·자원 한도가 포함된다.
  요청 처리와 공개 게임 데이터 준비에 사용한다. 게임 계정 비밀번호나 결제정보를 요구하지 않는다.
- 앱의 배열은 공통 Multi 기기 JS, Find·시드 탐색은 기기 Worker/JS/WASM에서 실행한다.
- 앱은 시드·결과를 자체 DB나 localStorage에 별도 보관하지 않는다. 실행 중 메모리와
  사용자가 ChatGPT에 보낸 입력·공유 요약까지 없어지는 의미는 아니다.
- 결과 공유는 사용자 버튼으로 실행한다. 공개 게임 풀 전체를 모델 대화에 보내지 않는다.
- OpenAI/ChatGPT와 Hugging Face의 통신·인프라 로그 및 보관은 각 서비스 정책 적용 대상이다.
  애플리케이션의 비저장을 근거로 모든 인프라 기록이 없다고 주장하지 않는다.
- 지원 이슈는 GitHub에 공개될 수 있다. 비밀 정보는 공개 이슈에 제출하지 않도록 안내한다.

소유자가 확정할 항목: 실제 운영자 공개 표기, 인프라 로그 접근/보관 방침, 개인정보 요청을
비공개로 접수할 연락 방법, 시행일. 확정 뒤 정식 정책을 공개하고 실제 URL을 검사한다.

## 이용 안내·약관 검토용 사실

이 절은 정식 약관이나 법적 동의문이 아니다. 소유자가 적용 내용을 검토한 뒤 게시한다.

- 무료 비공식 팬 도구이며 게임·ChatGPT 제공사의 공식 서비스가 아니다.
- 계산에는 사용자가 선택한 지역·배너·현재 시드·직전 결과·가정이 적용된다.
  잘못된 입력이나 게임 규칙/데이터 변경으로 예상과 달라질 수 있다.
- 티어는 출처가 있는 의견이다. 투자 조건·보유 전력·게임 진행에 따라 선택이 달라진다.
- 게임 계정 접속·재화 구매·대리 뽑기·시드 조작 기능이 없다.
- ChatGPT 계정별 사용량 제한, HF 가동 상태, 지원 범위는 서비스 안내에서 확인한다.

임의의 법적 면책·환불·관할·데이터 삭제 기한을 약속하지 않는다. 실제 운영 조건과 권리 범위를
소유자가 확인한 뒤 개인정보처리방침 및 약관을 공개 URL로 연결한다.

## 업데이트와 이전

이벤트/게임 데이터 및 호환되는 서버 결과 수정은 기존 HF 배포로 제공된다.
도구·스키마·설명·instructions·UI 참조/CSP 변경은 공개 후 지속 자동 검토를 거친다.
소개·아이콘·국가·패키지/skill 변경은 기존 플러그인의 새 ZIP과 버전 심사가 필요하다.

현재 제출 안내는 기존 MCP 서버 URL 변경을 포털에서 지원하지 않으므로 OpenAI 지원팀에 문의하라고 안내한다.
경로만 바꾸면 자동 수정된다고 가정하지 않는다. 지원팀 안내에 따라 새 등록이 필요한 경우에도
현재 서버·엔진·자료를 재사용할 수 있다. 새 endpoint와 UI origin, 공개 링크를 설정하고 도메인 검증·심사를 완료한다.
기존 사용자에게 새 플러그인 설치/연결을 안내하며 기존 설치가 자동 이전된다고 가정하지 않는다.
공개 도구 정의와 이미 발급한 UI resource URI는 전환 중에도 호환성을 유지해야 한다.
