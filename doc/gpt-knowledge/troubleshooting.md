# 예상과 다르거나 지원 범위가 헷갈릴 때

## 실제 뽑기와 다릅니다

추가 뽑기를 권하기 전에 현재 시드, 관측 시작/현재 시드 구분, 지역, 실제 배너 날짜, 직전 캐릭터,
일반/확정/특수 티켓 종류, 사이에 다른 뽑기를 했는지 순서대로 확인한다.
배너 이름만 같고 풀이 다르거나 미래 울슈레를 중복 추가했는지도 확인한다.
후보가 여러 개인 시드를 정답으로 고른 적이 있다면 다시 검증해야 한다.

## 이미 게임에서 뽑았어요

앱은 게임을 읽지 않으며 실제 뽑기·진행 기록을 자동 저장하지 않는다.
현재 MCP 앱의 이름 밑줄을 클릭하는 것으로 게임이나 시드가 자동 진행되지 않는다.
과거 시드를 그대로 넣어 다음 결과라고 답하지 않는다. 현재 시드를 확인하거나, 지원되는 연속 일반 관측으로 시드 찾기를 다시 안내한다.
기존 사이트 Multi의 진행·공유·PNG 기능이 MCP 앱에 모두 들어 있다고 약속하지 않는다.

## 냥티·럭티·이벤트 뽑기도 되나요?

현재 MCP의 검증 범위는 레어 뽑기 계열과 지원하는 특수 티켓 배열이다.
냥코 티켓·럭키/G 티켓·아이템 이벤트 뽑기·닼캣아 파밍과 이들 사이의 중복 조작은 이 안내로 검증하지 않았다.
일반 레어/플티와 같은 시드나 전환 규칙으로 계산해 주지 않는다. 냥티를 레티로 오인하지 않는다.
스텝업 구매 단계 전체를 관측 기록으로 해석하는 기능도 없다.

## 앱이 안 열리거나 결과를 못 읽을 때

앱의 다시 시도를 안내하거나 Catsroll 사이트 링크를 제공한다.
사용자가 계산한 뒤 결과 공유를 눌러야 GPT가 그 요약을 볼 수 있다. 화면을 볼 수 없으면 결과를 봤다고 말하지 않는다.
공유 요약에서 생략된 행·경로를 상상해서 채우지 않는다. 준비 데이터만 있으면 “계산 전”이라고 설명한다.
현재 시험 버전에는 ChatGPT 첫 표시/답변 표시 문제와 무료 계정 수용 검증이 남아 있다.

관련 문서: `seed`, `banners`, `find`.
