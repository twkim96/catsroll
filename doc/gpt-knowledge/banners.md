# 배너 선택, 날짜와 신캐 추가

실제 지역·날짜의 풀을 먼저 확인한다. 미리보기는 참고용이며, 배열 결과는 사용자 기기에서 계산하기 전에는 예측하지 않는다.

## 배너와 캐릭터 찾기

같은 시드라도 배너의 캐릭터 목록·순서·확률이 다르면 결과가 달라질 수 있다. 실제 게임 지역과 뽑을 날짜에 맞는 배너를 찾고, 한국판과 일본판 풀이 같다고 가정하지 않는다.

배너 이름이나 날짜는 `catsroll_events`로 정확한 이벤트 ID를 찾는다. 배너명·시리즈명·별명을 개별 고양이로 검색하지 않는다. 예를 들어 다마군/다군은 다이너마이트 군단 배너다. `catsroll_cats`에서 이름이 나오지 않아도 배너가 없다는 뜻은 아니다. 캐릭터를 뽑고 싶으면 `catsroll_cats`로 ID를 찾은 뒤 `catsroll_events(cat_id=ID, lang=지역)`로 실제 포함 배너를 확인한다. 검색 결과만으로 배너 포함을 단정하지 않는다.

같은 이름의 배너가 여러 개면 지역·기간·확정 여부를 확인하고 필요하면 앱의 선택 메뉴에서 고르게 한다. 현재 데이터에 풀이 없으면 과거 배너를 참고 시뮬레이션으로만 제안하고, 실제 풀·순서·확률·버전이 같은지 확인하지 못한 경우 실제 예측이라고 말하지 않는다.

## 현재 풀과 준비 조건

준비할 때 목표가 선택한 일반 배너나 사용자가 허용한 티켓 풀에 포함되는지 확인한다. 특수 티켓은 목표별 허용과 티켓 예산이 모두 필요하다. 확인되지 않으면 포함 배너를 다시 찾는다.

기간·풀·계산 결과를 안내 문서에 고정하지 않는다. 실제 배열은 사용자가 기기에서 계산한 결과를 따른다. 표시·탐색 범위가 없으면 100행을 준비하고, 명시한 범위는 최대 300행 안에서 유지한다. 실제 경로의 뽑기 수는 결과의 `totalDraws`로 확인한다.

## 예정 배너 미리보기

아직 일정이 정해지지 않은 배너 요청에는 `catsroll_banner_preview(query=배너명, lang=실제 게임 지역)`을 사용한다. 기존 시리즈·캐릭터 ID와 KR·JP 카탈로그의 이름·별명으로 연결하고, 지역별 최신 기간과 풀을 비교한다. 후보 시리즈나 같은 날 변형이 여러 개면 선택을 확인한다.

일본에 더 최신 풀이 있으면 참고 시뮬레이션을 제안할 수 있다. `prepare_rows`의 `lang`은 데이터 출처, `previewFor`는 사용자의 게임 지역이다. 이를 `catsroll_prepare(mode="multi", seed=사용자시드, rows=prepare_rows)`에 넘기며, 계산은 사용자가 실행한다.

한국어 이름이 없으면 원문 이름과 ID를 유지하며, 다른 캐릭터를 대신 넣거나 신캐 자리를 임의로 추가하지 않는다. 출처 배너 기간은 참고 풀의 과거/기존 기간이지 한국판 미래 복각 일정이 아니다. 지역별 풀 순서·확률·확정 조건이 다르면 결과도 달라질 수 있다. 미정 배너는 날짜 순서 탐색 `scheduleAware=false`로 계산하고 실제 일정이 나오면 다시 조회한다.

## 미래 울슈레 가정

`ubers`는 해당 배너 울슈레 풀 앞에 가상 새 캐릭터를 추가하는 계산 옵션이다. `(-1?)` 같은 표시는 이름을 확정하지 않은 자리이며, 이 옵션으로 미래 캐릭터의 이름·정확한 순서·출시일을 알 수 없다.

서버에 이미 실제 새 배너가 있으면 기본 `ubers=0`을 사용해 같은 신캐를 중복 추가하지 않는다. 신캐가 없는 배너에 일괄 추가하거나 “신캐는 항상 확뽑 때 추가된다” 같은 규칙을 만들지 않는다.

## 플래티넘·레전드 티켓

일반 레어 배너와 플래티넘·레전드 티켓은 서로 다른 풀이다. 일반 배너의 확률업·콜라보 개최나 한 배너의 신캐 추가만으로 모든 티켓 풀이 바뀐다고 말하지 않는다. 목표 ID가 티켓 풀에 실제 포함되는지, 사용할 날짜의 티켓 풀과 현재 시드·직전 결과에서 위치가 어디인지 확인한다. 레전드 티켓의 레레 결과와 일반 배너의 레레 색상 칸을 같은 것으로 취급하지 않는다. 콜라보에 별도 레어가 있으면 배너를 섞을 때 중복 경로도 바뀔 수 있다.

플티로 정규 캐릭터를 얻는 것이 무조건 손해는 아니다. 그 캐릭터의 필요성, 정규 배너의 대안 경로, 티켓으로 얻고 싶은 다른 미보유 캐릭터를 비교한다. 현재 티켓 수와 허용 확뽑 횟수를 임의로 늘리지 않는다. 성능은 `recommendations`, 실제 소모·획득 순서는 `find`를 참고한다.

## 배너 변경과 시드

배너/티켓 풀 변경과 시드 변경은 다른 일이다. 같은 현재 시드라도 새 풀로 계산하면 결과가 달라질 수 있다. 특정 날짜나 신캐 발표만으로 모든 배너가 바뀐다거나 매달 같은 날 전체 배열이 초기화된다고 말하지 않는다. 실제 적용 풀·순서·확률을 확인하고, 업데이트 뒤 결과가 맞지 않으면 `troubleshooting` 절차를 따른다.

같은 시드 숫자를 다른 지역 풀의 참고 계산에 사용할 수 있지만, 지역을 바꿔 조회했다고 게임 계정의 시드가 바뀌지는 않는다. 풀·순서·확률·확정 설정이 다르면 동일 결과를 보장하지 않는다. 일본판 기간을 한국판 확정 일정으로 옮기거나 특수 콜라보 보너스·상품 단계를 추측하지 않는다.

관련 문서: `find`, `colors`, `troubleshooting`.
