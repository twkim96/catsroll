# 처음 시작: 배열로 무엇을 할 수 있나요?

## 짧은 답

배열은 현재 시드와 선택한 배너에서 앞으로 나올 뽑기를 계산해 보는 표다.
게임의 결과를 바꾸거나 대신 뽑아 주는 기능은 아니다. 배너를 고르기만 해서는 시드가 진행되지 않는다.
일반 레어 뽑기와 플래티넘·레전드 티켓은 공통 진행 상태를 사용하므로, 실제로 다른 뽑기를 했다면 이후 예측도 함께 바뀐다.

## 먼저 물을 것

- “지금 시드 숫자를 알고 있나요? 모르면 최근 뽑은 결과로 찾는 것부터 도와드릴게요.”
- 시드를 안다면 “한국판인가요, 일본판인가요? 보고 싶은 배너나 얻고 싶은 캐릭터가 있나요?”

“배열 봐줘”만으로는 뽑기 결과를 추정하지 않는다. 시드가 없으면 `seed`, 목표가 있으면 `find` 안내로 이어 간다.

## 도구 흐름

1. `catsroll_guide`로 해당 개념을 확인한다.
2. `catsroll_events`로 배너 이름·시작일을 확인하고 정확한 ID를 고른다. 앞으로의 배열 조회에서 날짜를 생략하면 현재 배너를 우선하고, 서로 다른 현재 후보가 있으면 차이를 확인한다. 지난 뽑기로 시드를 찾을 때는 실제 뽑은 배너/기간을 확인한다.
3. `catsroll_prepare(mode="multi")`로 앱을 준비한다. 표시·탐색 범위는 기본 100행(최대 300행)이며 실제 경로에서 사용하는 뽑기 수와 다르다. 총 뽑기 수는 계산 결과의 `totalDraws`로 확인한다. 미래 울슈레는 0이 기본이다. 일반 배열 조회에 목표 캐릭터는 필요 없다. 캐릭터 획득 경로를 요청한 경우에만 목표와 Find를 사용한다.
4. “앱에서 계산을 눌러 주세요. 설명을 원하면 결과를 GPT에 전달해 주세요.”라고 안내한다.

“한국판이고 시드는 12345, 포노가 갖고 싶어”처럼 자연스럽게 말하면 된다.
실제 게임에서 뽑기를 실행하거나 이미 뽑은 내역을 자동으로 기록하는 기능은 현재 앱에 없다.

관련 문서: `seed`, `find`, `troubleshooting`.
