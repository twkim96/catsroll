# 원하는 캐릭터까지의 경로 찾기

## 짧은 답

Find는 선택한 배너들을 어떤 순서로 뽑으면 목표를 얻는지, 정한 범위와 자원 한도 안에서 탐색한다.
표에 목표가 보인다는 사실만으로 현재 위치에서 갈 수 있다고 판단하지 않는다. 경로는 중복 레어·확정·티켓 사용을 함께 계산해야 한다.

## 초심자에게 물을 것

1. 현재 시드와 게임 지역. 모르면 `seed`부터 안내한다.
2. 원하는 캐릭터 이름. `catsroll_cats`로 ID를 찾고 별명이 애매하면 확인한다.
3. 사용할 배너와 “확뽑·플티·레전드 티켓을 써도 되나요? 각각 최대 몇 번인가요?”

세 항목을 한꺼번에 묻지 않는다. 처음에는 시드 유무와 목표만 확인하고,
다음 차례에 필요한 배너·허용 자원을 좁힌다.
이미 말한 정보는 다시 묻지 않는다. 사용자가 모르는 기술 옵션을 한꺼번에 늘어놓지 않는다.
허용받지 않은 티켓/확뽑은 한도를 0으로 유지한다. 각 목표의 `allow_ticket`과 티켓 총 한도는 별도 설정이다.

## 준비와 설명

`catsroll_prepare(mode="find")`에 목표·배너·허용 자원을 넣고 앱에서 계산하게 한다.
현재 Find는 한 지역의 배너끼리 사용한다. 기본 범위는 100행이며 필요한 경우 최대 999행까지 늘릴 수 있다.
서로 다른 날짜의 배너를 실제로 사용할 계획이면 `scheduleAware=true`로 일정 순서도 확인한다.
기본값 false로 얻은 결과를 “오늘 전부 실행 가능”이라고 말하지 않는다.

공유된 결과에서 시작 위치, 사용할 배너, 일반/확정/티켓 행동, 획득 목표, 다음 위치를 순서대로 짧게 설명한다.
비용 모드는 사이트가 정한 가중치로 비교한다. 게임의 실제 현금·통조림 비용을 계산한 값으로 바꾸어 말하지 않는다.
“가장 싸게”와 “가장 적은 이동”은 다를 수 있다. 사용자가 원할 때 기준을 좁힌다.

## 결과의 한계

- `success`: 입력한 조건 안에서 찾은 경로다.
- `impossible`: 설정한 배너·범위·자원으로 경로를 못 찾았다는 뜻이다. 영원히 획득 불가라는 뜻은 아니다.
- `limit` / `partial`: 탐색 한도. 최적성이 확인된 완성 답처럼 설명하지 않는다.
- `cancelled` / 중단: 실행을 마친 결과가 아니다.

관련 문서: `tracks`, `guaranteed`, `banners`.
