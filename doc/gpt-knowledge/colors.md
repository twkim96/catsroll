# 표의 색상은 어떻게 읽나요?

## 짧은 답

Catsroll의 기본 셀 색은 엔진의 난수 점수 구간을 나타낸다. **색과 실제 희귀도는 항상 일대일이 아니다.**
확률업 배너·플래티넘·레전드 티켓에서는 같은 색 구간이라도 나오는 희귀도가 달라질 수 있다.
획득 캐릭터는 선택한 배너에서 계산한 이름·희귀도·경로로 판단한다.

| 색 | 기본 의미 |
| --- | --- |
| 흰색 | 기본 레어 점수 구간 |
| 노랑 | 일반 배너와 축제 배너 사이에서 레어/슈레가 달라질 수 있는 구간 |
| 금색 | 기본 슈레 점수 구간 |
| 연한 빨강·살몬색 | 배너 확률에 따라 슈레/울슈레가 달라질 수 있는 구간 |
| 빨강 | 기본 울슈레 점수 구간 |
| 연보라 | 레레 확률 차이의 영향을 받을 수 있는 경계 구간 |
| 진보라 | 기본 레레 점수 구간 |
| 하늘색·아쿠아 | 원본 엔진의 한정 캐릭터 ID 목록에 따른 강조. 난수 구간과 별개 |

금색이면 무조건 슈레, 보라색이면 모든 배너에서 무조건 레레라고 말하지 않는다.
“빨간 칸이니까 이 캐릭터를 얻는다”라고 색만으로 추론하지 않는다.
현재 MCP 앱의 하늘색은 보유 캐릭터 표시가 아니다. 다른 사이트의 Owned·초록색 Find next 강조 설명을 이 앱의 기능으로 옮기지 않는다.
칸 안의 R/G/RG·다음 위치는 색과 별도로 읽어야 한다.

검증 기준: `TrackEngine.Cat.scoreRarityLabel`, `TrackEngine.EXCLUSIVES`, GPT 앱의 원본 색상 매핑.
관련 문서: `tracks`, `guaranteed`.
