# 냥코 줄임말을 읽는 법

캐릭터·배너 별명은 검색 도구로 현재 이름과 ID에 연결한다. 한국어 축약도 유효한
별명이다. 예를 들어 문단은 고타츠양이의 3진 고양이 문어단지, 라길은 고양이 로커의
3진 고양이 라면의 길이다. 별명으로 진화형을 말해도 뽑기에서는 같은 캐릭터 ID를 찾는다.

- 배너/뽑기 시리즈: 다군·다마군, 닼히, 갓즈, 울소, 갤걸, 드엠, 아워즈,
  울고축·하고축·울하고축은 `catsroll_events(query=...)`로 찾는다.
- 캐릭터: 문단·라길·암테·크놋·아이캣·백슬리·흑슬리·백포노·흑포노 등은
  `catsroll_cats(query=...)`로 찾는다. 실제 풀 포함 여부는 ID를 얻은 뒤 배너 도구로 확인한다.
- 블아는 축제 한정 캐릭터군을 가리키는 표현이다. 단일 캐릭터나 단일 배너로 고정하지 않는다.
  쌍포노·쌍슬리도 각각 두 캐릭터를 묶는 표현이므로 한 ID로 바꾸지 않는다.
- 드론·하데스·해커와 계절형을 포함할 수 있는 이름은 검색 결과와 문맥을 확인한다.
  고대 가면신 드론 같은 EX 캐릭터는 현재 뽑기 캐릭터 검색의 대상이 아니다.
- 에바·스파·썸걸은 배너 시리즈가 여러 개일 수 있다. 지역·날짜·후보 차이를 확인한다.

## 자주 쓰는 일반 용어

| 표현 | 의미와 다음 확인 |
| --- | --- |
| 레티 | 레어 티켓. 시드 찾기에는 실제 일반 뽑기 관측 순서를 사용 |
| 플티 | 플래티넘 티켓. 일반 배너와 다른 전용 풀 |
| 블티 | 이 자료에서는 레전드 티켓. 플티와 구별하고 현재 티켓 풀을 확인 |
| 확뽑 | 울슈레 확정이 포함되는 묶음 뽑기. ‘10회’라는 옛 글 표현을 그대로 입력하지 말고 현재 배너의 묶음 조건을 확인 |
| 레레 / 슈레 / 울슈레 | 레전드 레어 / 슈퍼 레어 / 울트라 슈퍼 레어 |
| 빨적 / 검적 / 뜬적 / 흰적 | 빨간 적 / 검은 적 / 떠있는 적 / 속성 없는 적 |
| 고방 / 양딜 / 딜탱 | 고기방패 / 양산 딜러 / 공격·탱킹을 함께 맡는 역할 |
| 원범 / 공무 / 공다 / 공업 | 원거리 범위 공격 / 공격 무효 / 공격력 감소 / 공격력 상승 |
| 엄강 / 초뎀 / 극뎀 / 살남 | 엄청 강하다 / 초 데미지 / 극 데미지 / 살아남는다 |
| 냥콤 / 대구력 / 중구력 | 냥콤보 / 연구력 대 / 연구력 중. 구성원과 해금 조건은 별도 확인 |
| 뉴절먹 | 신규 캐릭터 확보를 권하는 커뮤니티 표현. 보유 상태·목적·예산에 따라 판단 |
| 기캐 | 기본 9종 등을 뜻하기도, 무과금 획득 캐릭터를 넓게 뜻하기도 하므로 문맥 확인 |
| 구레 / 신레 / 레제로 | 구 레전드 / 신 레전드 / 레전드 제로 |
| 스업 / 트레 / 도령 / 냥컴 / 스냥 | 스피드 업 / 트레저 레이더 / 고양이 도령 / 냐옹컴 / 스냥이퍼 |
| 감토 / 캣아 / 닼캣아 | 가마토토 / 캣츠아이 / 다크 캣츠아이 |
| 본능 / 초본 / 4진 | 본능 / 초본능 / 4단 진화. 초본능과 4진은 다른 강화 조건 |
| 본능옥 / D옥 | 본능옥 / D등급 본능옥. 장착·보관·합성/교환 판단은 `recommendations` 참고. 현재 효과·규칙을 확인해 설명 |
| 냥티 / 럭티 / 럭티 G | 냥코 티켓 / 럭키 티켓 / 럭키 티켓 G. 현재 MCP의 일반 레어 뽑기 계산과 지원 범위를 구별 |

이 안내는 단어 해석용이다. 원문의 출시 예정 표기, 상시 복각 가정, 피해 배율,
능력의 적용 조건, 재화 비용·보상·스테이지 규칙을 최신 사실로 복사하지 않는다.
캐릭터의 현재 형태·능력은 게임 데이터, 배열은 선택한 풀과 기기 계산 결과를 우선한다.

## 추가 자료의 묶음 별명과 오기

세2마는 세이버·에바 2호기·토모에 마미, 세2마춘은 여기에 춘리, 2마는 에바 2호기·마미를
묶은 표현이다. 춘블발은 춘리·블랑카·발로그, 쿠블아는 쿠니오군·블랑카·외눈의 소녀 아스카를
가리킨다는 사용자 자료의 용례다. 한 캐릭터 ID가 아니며 ‘전부 보유/목표’인지 문맥을 확인한다.
실제 현재 이름과 풀은 각 캐릭터·배너 도구로 다시 조회하고 묶음 자체에 성능 등급을 붙이지 않는다.

추가 목록의 ‘레티=레전드 티켓’, ‘베카=고양이 신지’는 사용하지 않는다. 레티는 레어 티켓,
베카는 고양이 베이비의 베이비카트 계열이다. 대공·사키·아스카·카오루 등은 검색 후보와
배너 문맥을 함께 본다. 신규 축약과 전체 대조 기록은 [별명 검토](../gpt-alias-review.md)에 있다.
