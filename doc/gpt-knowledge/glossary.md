# 냥코 줄임말을 읽는 법

별명은 검색 단서다. 현재 이름·ID·배너 풀은 데이터 조회로 확인한다.

## 배너·캐릭터 별명

한국어 축약도 검색 별명으로 사용한다. 별명으로 진화형을 말해도 뽑기에서는 같은 캐릭터 ID를 찾는다. 현재 이름과 ID는 도구 검색 결과로 확인한다.

- 배너/뽑기 시리즈: 다군·다마군, 닼히, 갓즈, 울소, 갤걸, 드엠, 아워즈, 울고축·하고축·울하고축은 `catsroll_events(query=...)`로 찾는다.
- 캐릭터: 문단·라길·암테·크놋·아이캣·백슬리·흑슬리·백포노·흑포노·베카 등은 `catsroll_cats(query=...)`로 찾는다. 문단은 고타츠양이의 3진 고양이 문어단지, 라길은 고양이 로커의 3진 고양이 라면의 길을 가리킨다. 베카는 고양이 베이비의 베이비카트 계열을 가리킨다. 실제 배너 풀 포함 여부는 캐릭터 ID를 얻은 뒤 배너 도구로 확인한다.
- 블아는 축제 한정 캐릭터군을 가리키며 단일 캐릭터나 배너로 고정하지 않는다. 쌍포노·쌍슬리도 둘씩 묶는 표현이므로 한 ID로 바꾸지 않는다.
- 드론·하데스·해커처럼 계절형을 포함할 수 있는 이름은 검색 결과와 문맥을 확인한다. 고대 가면신 드론 같은 EX 캐릭터는 현재 뽑기 캐릭터 검색의 대상이 아니다.
- 에바·스파·썸걸은 여러 배너 시리즈를 가리킬 수 있으므로 지역·날짜·후보를 확인한다.
- 대공·사키·아스카·카오루처럼 검색 후보나 배너 문맥에 따라 뜻을 확인해야 하는 이름은 지역과 이벤트도 함께 살핀다.

## 묶음 별명

세2마는 세이버·에바 2호기·토모에 마미, 세2마춘은 여기에 춘리, 2마는 에바 2호기·마미를 묶은 표현이다. 춘블발은 춘리·블랑카·발로그, 쿠블아는 쿠니오군·블랑카·외눈의 소녀 아스카를 가리킨다는 사용자 자료의 용례다. 한 캐릭터 ID가 아니므로 ‘전부 보유/목표’인지 문맥을 확인한다. 현재 이름과 풀은 캐릭터·배너 도구로 다시 찾고 묶음 자체에 성능 등급을 붙이지 않는다.
