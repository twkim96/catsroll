# Catsroll for ChatGPT

Catsroll은 냥코대전쟁의 시드 찾기, 여러 배너 배열 비교, 목표 캐릭터 획득 경로 탐색을 돕는 무료 팬 도구입니다.
소스 저장소와 운영 계정은 [twkim96/catsroll](https://github.com/twkim96/catsroll)입니다.
PONOS 또는 OpenAI의 공식 게임 서비스가 아닙니다.

## 할 수 있는 일

- 처음 사용하는 분의 배열·시드·확정 뽑기 질문을 짧은 안내로 연결합니다.
- 한국판·일본판 배너와 캐릭터를 찾고, 부족한 적 속성에 맞는 성능 후보를 제안합니다.
- 관측한 뽑기 결과로 시드 후보를 찾습니다.
- 시드와 배너를 선택해 Multi 배열을 비교하고, 자원 조건에 맞는 Find 경로를 탐색합니다.

계산은 앱의 버튼을 누른 뒤 사용자 기기에서 실행합니다. 서버는 공개 게임 데이터와 앱을 제공합니다.
게임 계정 로그인, 대신 뽑기, 재화 구매·결제, 게임 서버 변경 기능은 없습니다.
추천 티어는 출처의 의견이며 진화형·본능 조건을 함께 확인해야 합니다.

## 현재 공개 상태

HF의 [웹 미리보기](https://twkim96-my-cats-rolls.hf.space/gpt)와 개발용 ChatGPT 연결은 시험 중입니다.
플러그인 디렉터리 공개 심사·출시 및 무료 ChatGPT 계정 수용은 아직 완료되지 않았습니다.
별도의 Catsroll 이용료는 없으며 ChatGPT 자체의 계정별 이용 조건과 사용량 제한은 별도입니다.
