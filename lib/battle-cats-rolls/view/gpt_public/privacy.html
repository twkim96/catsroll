이 방침은 Catsroll의 ChatGPT 연동 도구와 /gpt 앱에서 처리하는 정보에 적용됩니다.

요청에서 처리되는 정보

요청 기능에 따라 지역, 배너, 캐릭터, 시드, 관측한 뽑기 결과와 자원 조건이 포함될 수 있습니다. ChatGPT에서 요청을 실행하면 Catsroll 서버는 요청 처리와 공개 게임 풀 및 앱 입력 준비를 위해 해당 입력을 일시적으로 받습니다. 게임 계정 비밀번호나 결제 정보를 요구하지 않습니다.

기기 계산과 공유

배열·Find·시드 탐색 계산은 사용자 기기의 메모리에서 실행합니다. 앱은 계산 중인 시드와 결과를 자체 데이터베이스나 localStorage에 별도로 보관하지 않습니다. 이는 실행 중 메모리의 데이터나 사용자가 ChatGPT에 보낸 입력·공유 요약까지 없어지거나 다른 서비스가 보관하지 않는다는 뜻은 아닙니다.

사용자가 앱의 공유 버튼을 누르면 계산된 전체 배열, Find 경로, 플랜과 입력 조건을 Catsroll 서버 메모리에 최대 1시간 임시 보관하고, 요약과 비밀 결과 ID를 대화에 전달합니다. 이후 모델이 결과 조회 도구로 필요한 구간을 읽을 수 있습니다. 공개 게임 풀 전체는 보내지 않습니다. 상세 조회가 지원되지 않으면 기존 방식으로 계산 요약만 대화에 전달하며, 이때 생략된 범위를 표시합니다. ChatGPT/OpenAI와 Hugging Face가 처리하는 대화, 요청 및 인프라 기록에는 각 서비스의 정책이 적용됩니다.

보관과 서버 진단 기록

Catsroll의 MCP 처리 코드는 정상 요청의 본문을 별도 요청 이력 파일이나 데이터베이스에 기록하지 않습니다. 공유하지 않은 기기 계산 결과와 플랜은 현재 앱의 실행 메모리에 유지됩니다. 공유한 전체 스냅샷은 서버 메모리에 최대 1시간만 보관하고 파일이나 데이터베이스에 쓰지 않습니다. 만료 시 조회할 수 없으며 메모리 정리는 다음 요청 때 수행합니다. 서버 재시작 시에는 더 일찍 사라질 수 있습니다. 조회는 보관 기간을 연장하지 않습니다. 결과 ID는 해당 연결에서 읽기 권한을 주는 비밀값으로, ID를 아는 사람은 조회할 수 있으므로 공개 게시하지 마세요. 로그인 계정별 보관함이나 공개 결과 목록은 제공하지 않습니다. 앱을 닫아도 ChatGPT 대화에 이미 보낸 정보가 함께 삭제되는 것은 아닙니다.

서버의 시작·종료·오류 진단은 표준 출력과 오류 출력으로 전달될 수 있습니다. 오류 종류·메시지·코드 위치가 포함될 수 있으며 운영자는 장애 조사 시 호스팅의 진단 기록을 확인할 수 있습니다. Catsroll에는 별도의 요청 원문 수집기나 진단 로그 보관 데이터베이스가 없습니다.

Hugging Face 등 서비스 제공자는 접속 시각·IP 주소·기기 정보 등 자체 접속·보안 정보를 처리할 수 있습니다. 해당 기록의 접근과 보관은 제공자의 정책을 따르며 Catsroll이 모든 인프라 기록의 삭제 시점을 정하거나 보관 기간을 보장하지 않습니다. 이메일 문의의 보관 기간은 아래와 같습니다.
