Catsroll 소개

Catsroll은 냥코대전쟁의 시드 찾기, 배너 배열 비교와 목표 캐릭터 경로 탐색을 돕는 무료 팬 도구입니다. 소스 저장소는 twkim96/catsroll입니다.

운영자: twkim (GitHub: twkim96). 서비스 이용 조건은 이용약관, 정보 처리 방식은 개인정보처리방침을 확인해 주세요.

현재 ChatGPT 연결과 공개 디렉터리용 자료를 준비·시험 중입니다. 디렉터리 제출, 승인, 공개 및 무료 계정에서의 사용은 아직 확인되지 않았습니다.

계산과 입력

배열·Find·시드 탐색 계산은 사용자 기기의 메모리에서 실행합니다. ChatGPT를 통해 요청을 보내면 선택한 지역·배너와 요청에 포함한 시드, 관측 결과, 자원 조건 등의 입력을 Catsroll 서버가 공개 게임 풀과 앱 입력을 준비하는 동안 받습니다. 앱 서버가 배열이나 Find 계산을 대신 수행하지 않습니다.

앱의 공유 버튼을 누르면 계산된 전체 결과를 서버 메모리에 최대 1시간 임시 보관하고 요약과 비밀 결과 ID를 대화로 보냅니다. 모델은 필요한 배열 구간·캐릭터 위치·경로·플랜을 결과 조회 도구로 읽을 수 있습니다. 상세 조회를 사용할 수 없는 연결은 기존 요약 공유를 사용합니다. 공개 게임 풀 전체는 보내지 않습니다.

서비스와 문의

ChatGPT/OpenAI와 Hugging Face의 대화·호스팅 인프라에는 각 서비스의 정책이 적용됩니다. 오류나 개선 요청은 공개될 수 있는 GitHub Issues에 남길 수 있습니다. 비밀번호, 결제 정보, 게임 계정 인증 정보와 공개하면 안 되는 개인정보를 이슈에 올리지 마세요.

게임 계정 로그인, 대리 뽑기, 재화 구매·결제 기능은 제공하지 않습니다. 추천 티어는 출처가 있는 의견이며, 게임 데이터와 진행 조건에 따라 선택이 달라질 수 있습니다.
